# Bank Marketing Campaign: Term Deposit Prediction

##  Описание бизнес-задачи
Цель проекта — разработать и внедрить ML-модель для предсказания того, откроет ли клиент банка срочный депозит по итогам телефонной маркетинговой кампании. Проект ориентирован на оптимизацию расходов контакт-центра: переход от сплошного "холодного" обзвона к таргетированному скорингу, максимизирующему чистую прибыль.

##  Стек технологий и архитектура
* **Язык и данные:** Python, Pandas, NumPy
* **Машинное обучение:** Scikit-Learn, XGBoost, CatBoost
* **Архитектура кода:** Использование `Pipeline` и `ColumnTransformer` для защиты от утечек данных (Data Leakage)
* **Оптимизация гиперпараметров:** байесовская оптимизация через **Optuna**

##  Ключевые метрики
Так как классы были сбалансированы, использовалась связка Accuracy и ROC-AUC (для оценки качества ранжирования клиентов).
* **Baseline (Константная модель):** ROC-AUC = 0.5000
* **Baseline (Logistic Regression):** ROC-AUC = 0.9038, Accuracy = 0.8128
* **XGBoost + Optuna:** ROC-AUC = 0.9233, Accuracy = 0.8442
* **CatBoost + Optuna:** ROC-AUC = 0.9240, Accuracy = 0.8558
* **CatBoost + Optuna (Без duration):** ROC-AUC = 0.7961, Accuracy = 0.7353
> *Примечание: Признак `duration` (длительность звонка) давал искусственно завышенные метрики (ROC-AUC ~0.92). Однако в реальном бизнесе длительность разговора неизвестна до момента совершения звонка. Исключение этого признака позволило построить честную предиктивную модель скоринга "до звонка" с реалистичным ROC-AUC = 0.7961.*

## Оценка бизнес-эффекта (Value-Based Evaluation)

Для демонстрации ценности модели для бизнеса была написана экономическая симуляция на несбалансированной тестовой выборке, отражающей реальные рыночные условия (**базовая конверсия ~10%**).

**Условия симуляции:**
* Стоимость одного звонка оператора (связь + рабочее время): **50 руб.**
* Чистая прибыль банка с одного открытого депозита: **1000 руб.**
* 
* ### Результаты оптимизации:
* **Без ML (Сплошной обзвон):** Приводит к высокой доле холостых вызовов. При обзвоне аналогичного объема базы чистая прибыль составляет **311 450 руб.**
* **С использованием ML:** Модель ранжирует клиентов по вероятности согласия. Максимальная точка прибыли достигается, если обзвонить всего **58.9%** базы.
* **Чистый финансовый эффект:** Прибыль возрастает до **629 550 руб.** Внедрение модели приносит **+318 100 руб. чистой прибыли** (+102% к базовому сценарию) только на тестовом пуле клиентов.


##  Бизнес-инсайты (Feature Importance)
При интерпретации модели XGBoost выявлены следующие закономерности:
1. **Лояльность клиента:** Сильнейшим предиктором является успех предыдущих маркетинговых кампаний (`poutcome_success`).
2. **Фактор длительности звонка:** Признак `duration` имеет огромный вес, подтверждая правило продаж "чем дольше диалог, тем выше шанс сделки". Однако, для внедрения модели в production (скоринг до начала звонка) этот признак был проанализирован и подготовлен к исключению.
3. **Качество базы:** Звонки на неизвестные типы контактов (`contact_unknown`) резко снижают вероятность конверсии.
